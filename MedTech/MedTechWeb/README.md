# MedTechWeb - ASP.NET WebForms Excel Export Module

## Описание

Модуль `MedTechWeb` - это ASP.NET WebForms приложение (.NET Framework 4.8) с функцией экспорта данных в Excel с визуальными индикаторами загрузки (спинер).

## Основные компоненты

### 1. Pages/ExportPage.aspx
- **ASPX разметка** с Bootstrap 3 стилями
- **Интерфейс**:
  - Кнопка "Экспорт" (Bootstrap 3 `btn btn-primary`)
  - Спинер загрузки "Загрузка" (скрыт по умолчанию)
  - Спинер закрывает область контента при появлении
  - Информационный блок с инструкциями
  - Контейнер для вывода сообщений об ошибках/успехе

### 2. Pages/ExportPage.aspx.cs
- **Код-бихайнд** с логикой экспорта
- **Функциональность**:
  - Обработка события `BtnExport_Click`
  - Валидация запроса экспорта
  - Работа с базой данных через `DataManager`
  - Формирование Excel файла
  - Отправка файла клиенту
  - Обработка ошибок с логированием

### 3. Managers/DataManager.cs
- **Менеджер работы с данными**
- **Функции**:
  - `GetData()` - получение данных из БД
  - `ValidateData()` - валидация данных перед экспортом
  - Логирование ошибок в Event Log

### 4. Helpers/ExcelExportHelper.cs
- **Помощник для работы с Excel**
- **Функции**:
  - `ExportToExcel()` - конвертация DataTable в Excel файл (XLSX)
  - `GenerateFileName()` - генерация имени файла с временной меткой
- **Библиотека**: ClosedXML для работы с Excel

### 5. Helpers/SecurityHelper.cs
- **Вспомогательные функции безопасности**
- **Функции**:
  - `HtmlEncode()` - защита от XSS атак
  - `IsValidFileName()` - валидация имен файлов

### 6. Global.asax
- **Глобальные обработчики приложения**
- **Функции**:
  - `Application_Error()` - централизованная обработка ошибок
  - Логирование в Event Log

## Сценарий использования

1. Пользователь открывает страницу `ExportPage.aspx`
2. Нажимает кнопку "Экспорт"
3. На странице появляется спинер загрузки
4. Кнопка становится неактивной (disabled)
5. На серверной стороне:
   - Выполняется запрос к БД (DataTable)
   - Формируется Excel файл из полученной таблицы
   - Файл отправляется клиенту через `Response.BinaryWrite()`
6. После получения файла спинер исчезает
7. Кнопка "Экспорт" становится снова доступной

## Технические особенности

### Интеграция с Excel
- **Библиотека**: ClosedXML 0.95.4
- **Формат**: XLSX (Office Open XML)
- **Функции**: 
  - Автоматическое форматирование заголовков (жирный шрифт, серый фон)
  - Автоматическое подстраивание ширины колонок

### Безопасность
- **Валидация на серверной стороне** перед экспортом
- **CSRF защита** - проверка referrer
- **XSS защита** - HTML-кодирование выводимых данных
- **Обработка ошибок** с выводом безопасных сообщений пользователю

### Логирование
- **Event Log** - логирование ошибок и предупреждений в Windows Event Log
- **Безопасное логирование** - обработка исключений при логировании

### Кодировка
- **UTF-8** - корректное содержание типа при отправке файла
- **Content-Type**: `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`

## Конфигурация

### Web.config
Требуется строка подключения к БД (если используется реальная БД):
```xml
<connectionStrings>
    <add name="DefaultConnection" 
         connectionString="Server=.; Database=MedTech; Trusted_Connection=true;" 
         providerName="System.Data.SqlClient" />
</connectionStrings>
```

### packages.config
Зависимости:
- ClosedXML 0.95.4
- DocumentFormat.OpenXml 2.7.2

## Установка и развертывание

1. Добавить проект `MedTechWeb` в Visual Studio
2. Установить NuGet пакеты (ClosedXML, DocumentFormat.OpenXml)
3. Настроить строку подключения в `Web.config`
4. Развернуть на IIS Server

## Обработка ошибок

Приложение перехватывает следующие типы ошибок:
- Ошибки подключения к БД (SqlException)
- Ошибки при формировании Excel файла
- Некорректные запросы
- Общие исключения

Все ошибки логируются в Windows Event Log и выводятся пользователю в виде Bootstrap Alert.

## JavaScript (минимальное использование)

- `showSpinner()` - отображение спинера
- `hideSpinner()` - скрытие спинера
- `handleExportSuccess()` - обработка успешного экспорта
- `handleExportError(message)` - обработка ошибки экспорта
- `showAlert(type, title, message)` - отображение сообщения пользователю

JavaScript используется только для управления UI элементами, основная логика на серверной стороне C#.

## Запросы к БД

Текущая версия использует демонстрационный запрос (UNION ALL). Для использования реальных данных:

```csharp
// Замените в DataManager.GetData():
var query = @"SELECT * FROM YourTable";
```
